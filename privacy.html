Who uses this app

This app is a private tool used only by its owner. It is not available to the public.

What Google data it accesses

With the owner's permission, the app accesses the owner's own Gmail, Google Drive, Docs, Sheets and Calendar data to carry out tasks the owner requests.

  • Google data is never sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be removed at any time at myaccount.google.com/permissions.
